# BrightSteps 3.5.16

- Removed the visible circular glow/shadow behind the Piggy Bank and Treasure Chest.
- Enlarged both internal currency windows so coins, marbles, stars, and points remain fully visible.
- Re-spaced stored currency into clear bottom-up rows, reducing overlap and clipping.
- Reduced stored coin/marble bitmap size slightly so complete items remain visible at container edges.
- Currency now progressively fills from the bottom to the top instead of instantly showing full when no reward goal exists.
- Added default visual capacities for no-goal profiles: 25 stars, 50 marbles, 100 points, or 50 coins.
- Removed pig/chest glass overlays and glow layers that were visible in the profile screenshots.
- Preserved the front-edge masking layer so currency still reads as being inside the Piggy Bank or Treasure Chest.
- Increased task-completion animation space for the corrected larger containers.
