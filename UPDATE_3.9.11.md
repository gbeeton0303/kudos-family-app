# Kudos 3.9.11

## Stored currency pulse
- Fixed the stored-currency swelling animation so it is clearly visible.
- Previous pulse was only 7.5% and shared a roughly 7.8-second shimmer cycle.
- Currency now pulses every ~2.15 seconds.
- Even/odd currency pieces pulse in opposite phases to create a lively layered pile instead of scaling the entire pile uniformly.
- Maximum visible swell is approximately 16%.

## Profile storage celebration
- Added a soft halo, seven radiating light beams, and five small sparkle accents behind the storage container.
- Decoration uses the selected currency/accent color plus soft gold.
- Effects are placed entirely within the existing storage artwork region and do not increase profile card height or alter layout.
- Decorations are non-interactive so tapping the storage container still replays its animation.
