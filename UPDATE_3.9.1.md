# Kudos 3.9.1

## Home branding
- Replaced the parent-mode Home header star/logo with the supplied teal-laurel/gold-star icon.
- The replacement remains 43 × 43, matching the previous header icon footprint.
- Home title changed from `Kudos` to `Kudos Family`.
- `Kudos Family` uses the theme's strong teal/green branding color.
- Teacher Mode retains the classroom apple and `Kudos Classroom` identity.

## Parent Quick Start
- Replaced the Welcome page icon with the same supplied teal-laurel/gold-star artwork.
- Kept the existing Welcome icon display size unchanged.

## Home progress cards
- Rewards Progress and Daily Task Progress no longer sit on the very dark `surfaceStrong` panel.
- The outer progress carousel now uses a bright soft-teal surface with a subtle border.
- The inner progress cards use the normal surface color with a border.
- Headings and greeting copy now use high-contrast text/teal colors.
- Carousel dots use the teal primary color.

## Dark mode
- Rebalanced dark mode away from near-black/deep-teal values.
- Background and cards are now lighter layered teal shades with more visible separation.
- Muted text is brighter for readability.
- Borders and soft accent surfaces are more visible.
- Gold rewards remain warm and high contrast.
- Teacher dark mode received the same treatment with a slightly greener classroom tint.
