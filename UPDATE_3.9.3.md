# Kudos 3.9.3

## Home greetings
- Rewards Progress copy now says “their next assigned reward” rather than “its next assigned reward.”
- Removed the waving-hand emoji from both Home progress greetings.
- Greetings now end with an exclamation mark.
- Greeting automatically follows the device's local hour:
  - 5:00–11:59: Good morning
  - 12:00–16:59: Good afternoon
  - 17:00–4:59: Good evening

## Parent / Child Mode icons
- Replaced the Parent Mode icon with the supplied adult-outline artwork.
- Removed the supplied image background/interior and converted the adult outline to a transparent white icon.
- Replaced Child Mode with the supplied gold child figure.
- Removed the white sticker/background so only the gold child figure remains.

## Reward celebration replay
- Added a very small `↻ Replay` button to the reward celebration.
- Available for both a child-opened reward and a parent-sent reward.
- Replay restarts the card entrance, reward-icon bounce, glow, and confetti.
- Existing animation is stopped before replaying so repeated taps do not stack animation loops.
