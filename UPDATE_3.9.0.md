# Kudos 3.9.0 — Rebrand, theme, and tutorial readability

## Branding
- Visible app name changed from BrightSteps to Kudos.
- The supplied darker Kudos artwork is now the official app icon, splash image,
  adaptive icon artwork, and favicon.
- Image-picker permission copy now says Kudos.
- Existing technical slug, URL scheme, bundle identifier, Android package, and
  existing lowercase storage/technical identifiers remain unchanged so this
  build updates the existing app rather than behaving like a separate install.

## Theme
- Replaced the previous purple foundation with a bright teal/aqua + warm gold
  palette derived from the two supplied Kudos icon references.
- Light mode uses soft mint/white surfaces, teal primary actions, and gold
  rewards/achievement accents.
- Dark mode uses the deep teal of the official icon with brighter aqua primary
  accents and gold reward accents.
- Teacher themes were harmonized with the new branding while retaining a
  slightly greener classroom identity.

## Parent Quick Start
- Description text reduced from 28px to 17px with 24px line height.
- Tip copy reduced from 26px to 16px.
- Light-mode descriptions now use #505D5D: clearly dark gray, not black, while
  remaining high contrast.
- Dark-mode descriptions use a soft light gray.
- Vertical spacing was tightened so even the long Welcome page is designed to
  fit without requiring scrolling on a typical modern phone.
