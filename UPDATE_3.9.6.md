# Kudos 3.9.6

- Removed automatic reward-ready banner to prevent unwanted overlays and touch-lock issues.
- Early reward prompt now provides Cancel, Redeem now, and Send Reward.
- Reward celebration banner now says `Kudos <child name>!`.
- Profile progress is now horizontally swipeable: first page is Progress to next reward; second page is Today's Progress.
- Storage cards no longer display percent-full or visible Tap to replay text; the storage container remains tappable to replay.
- Next reward title/value is larger and uses the profile accent color beside the storage container.
- Restored one-by-one sequential currency drops during task completion.
- Task award badge pops large then returns to normal; fireworks begin near the last currency drops.
- Child Mode task submission now also plays the task-completion celebration before parent approval.
- Removed the profile hero glow/half-circle decoration.
- Profile editor now explicitly respects all safe-area edges and gives the top bar extra breathing room.
- Suggested Task Add vs Added controls now have much stronger visual contrast.
- Removed visible Replay text from reward celebration while retaining the replay control.
