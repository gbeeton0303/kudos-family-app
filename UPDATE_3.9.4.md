# Kudos 3.9.4

## Task completion celebration
- Rebuilt the task-completion particle effect to be much more playful.
- Four separate fireworks now burst around different sides of the storage container.
- Fireworks are staggered rather than appearing as one single ring.
- Added 28 pieces of multicolor confetti that explode outward from the storage container.
- Confetti spins, rises, spreads, and falls as the celebration finishes.
- All new effects are absolutely positioned and use native-driver transform/opacity animation only, so they do not change card height or move the screen behind the modal.

## Darker green buttons
- Deepened the app-wide primary green/teal colors to better match the dark teal used in the Kudos Home icon.
- `primary`, `primaryStrong`, `secondary`, and `success` were all adjusted in Parent and Teacher themes.
- Because action buttons throughout the app use these shared theme values, green buttons now have a more consistent darker branded appearance.
- Dark mode uses darker/more restrained teal action colors as well, while keeping enough contrast against dark surfaces.

## Home at-a-glance panel
- Rewards Progress / Daily Task Progress background changed from `#CFE9E3` to the slightly deeper `#B9D8D1`.
- Teacher Mode uses a similarly deeper classroom green (`#C8DDC5`).
