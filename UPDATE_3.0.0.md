# BrightSteps 3.0.0

- Added a fourth parent navigation tab: **Chore Chart**.
- Integrated and mobile-adapted the Family Task Rotation prototype using BrightSteps profiles.
- Renamed task/schedule terminology inside the rotation feature to **chore** and **chore chart**.
- Supports Monday–Friday and Monday–Sunday daily rotations, one-chore weekly 4-week rotations, multi-chore weekly 4-week rotations, and manual assignments.
- Added reusable chore pool, icon selection/custom photos, display styles, chart border themes, family-name titles, assignment cycling, and next-period navigation.
- Added native printing with Expo Print. **Print Chore Chart** opens the system print dialog so the user can choose an available printer.

After replacing the project, run `npx expo install expo-print` (or `npm install`) before starting the app.
